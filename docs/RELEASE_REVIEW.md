# 0.1.0 发布验收记录

审核日期：2026-11-24。本文件记录发布前的实际验证；公开版本与部署结果以 [GitHub Release](https://github.com/WuYuewy/Personal-Harness/releases/tag/v0.1.0) 和 [Actions](https://github.com/WuYuewy/Personal-Harness/actions) 为准。

## 交付范围

本目录为独立、通用的开源源码。保留 CLI、SDK、可选 UI、测试、示例、在线文档源文件和 CI。开发期真实运行数据库、凭据、个人配置、旧评估日志及私有网关资料均留在此目录之外。

默认采用离线配置演练，不提供内置供应商列表、默认端点、默认 Key 或特定部署的价格目录。新用户必须手动配置自己的通用 OpenAI 兼容连接。

## 本轮修缮

### 再次验收与图文文档

在另一个全新用户目录再次使用真实 Edge 登录并配置个人在线连接；测试参数与凭据仅保留在私有运行目录。首次模型表单中的地址、模型 ID 和价格为空，没有特定部署的快捷填参按钮。默认明亮模式已在操作系统偏好暗色的浏览器上下文验证，用户仍可自行切换。

本次实际完成的综合任务为社区读书会：本地汇总三笔费用 900 元；在线批量读取三份资料，确认必须项后的余额及宣传缺口均为 400 元，用最新 17:30 覆盖旧 18:00，保留 12 人、雨天安排、三位负责人和待确认项；审批前没有目标文件，批准后生成带来源的简报并验证下载字节相同。综合文件任务使用 4 次模型请求，费用按 usage 与测试连接价格计为 ¥0.0151056。

另外重测 4 页文字 PDF、账号称呼、偏好提取和确认、画像实际渲染、CSV 查找、待办、搜索、个人方案、场景创建/复制/归档/恢复、聊天及附件隔离、导出、手机地点筛选、零预算拦截，以及模型连接修改/新增/删除/重新选择。保存设置和本地功能均验证未新增模型请求。独立可重复浏览器冒烟还覆盖快捷查询保存、跨聊天复用、当前文件重读、编辑/删除。

本次共 10 次真实请求，计量 ¥0.0225206：其中正式再次验收 6 次、¥0.0209366；另有验收脚本误用仅聊天读取工作区的 4 次诊断请求、¥0.001584，费用同样保留，不能忽略。所有请求有完整 usage，无未知费用。原授权内合计占用 ¥0.7371628。再次尝试流式写入拒绝测试时，被每日剩余额度的保守预留拦截，没有发出新请求；该项真实 SSE 拒绝证据仍来自上表的首轮验收，不把本次拦截算作重新验证成功。

发现并修复 Chainlit 2.12 工具多选建议列表卸载后 `Array.from(undefined)` 造成的页面崩溃。本项目仅对生成的本地前端副本增加空列表保护；安装依赖原文件不变。新增回归检查以及实际浏览器复测通过。更改工具授权后应等待确认保存完成，再重新打开设置选择下一轮工具。

PDF 预览导航离开时观察到上游渲染 worker 的取消事件，以及 Windows 已关闭浏览器连接的重置日志；页面可继续操作、附件可重新打开，未造成任务或数据失败。测试脚本将预期的 worker 终止与实际页面异常分别记录，不将它当作模型故障。

文档新增 17 张本次明亮模式实际使用截图，配套可下载输入、实际产物和完整提示词，见 task-demo.md。截图只遮挡私有参数/本机路径，未伪造业务结果；使用图表只是短时演示计数。静态站图片可放大、桌面与手机布局另行验收。

1. 移除特定部署的运行时适配入口、价格表、模板和 UI 快捷预设，使用通用适配并保留用量有效性校验。
2. 修复原生工具多选框缺少可访问名称的问题；用实际标签关联输入，方便键盘、辅助技术和 UI 回归测试。
3. 修复首次页面依赖外部字体和数学公式 CDN 导致的加载等待。复用已安装的 Chainlit 构建，使用本地 KaTeX 样式和字体，保留许可证；不修改依赖安装文件。未拦截外部请求的全新登录页约 0.91 秒加载，实际外部资源请求为 0。
4. 增加可重复的浏览器冒烟、安装后 SDK/UI 冒烟、内容与路径发布审计，以及自包含的中文静态文档站。
5. 补齐可直接运行的示例资料、贡献指南、安全说明和第三方许可证说明。

## 仍然需要维护者理解的边界

这是一组有明确断言的本地发布验收，不能保证所有模型、所有网关和所有外部网络永远可用，也不等于长期节省已被证明。实时地图、OCR、通用 Shell、浏览器操作、原生手机应用和托管多用户服务不属于本版能力；详见 limits.md。

发布前已取得维护者的公开发布授权。使用说明托管于 [GitHub Pages](https://wuyuewy.github.io/Personal-Harness/)；构建与部署的最终状态见仓库 Actions。
