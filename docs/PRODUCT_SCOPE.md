# 产品目标与首版边界

Personal Harness 是面向个人日常任务、以用户配置为中心的轻量 Agent Harness。四个目标按同一条实际使用链落地：

| 目标 | 首版实现 | 不夸大的边界 |
| --- | --- | --- |
| 省钱 | 本地直达、个人任务方案、工具范围、结果分页、历史文件引用、可审计预算与有限升级 | 供应商缓存折扣单列；无统一节省比例承诺 |
| 个人 SDK 效率 | Agent/客户端复用、有界本地缓存、只读并发、批量读取、轻量配置 | IO 或等待下降不等于 API 费用下降 |
| 精简抽象 | Config → Agent → 原生工具，复用 PydanticAI；Chainlit 为可选 UI | 不建立通用多 Agent 编排平台 |
| 个性化与少数场景 | 账号助手偏好、可编辑记忆、场景/快捷方案、电脑 cowork、手机本地地点过滤 | 不把城市当成完整个性化；地图实时服务不在首版 |

判断完成的依据是：干净安装后能自主配置自己的在线模型、持续对话、处理附件、使用权限内工具并审批产物、查看费用、修改偏好、备份恢复；不能用离线脚本代替这些用户流程。具体记录见 RELEASE_REVIEW.md。

第一版保持本地优先、显式授权、真实费用可查。不会为凑功能引入未经使用验证的扩展服务，也不会宣称所有日常任务已经验证了长期节省。
