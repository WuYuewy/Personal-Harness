# Personal Harness

你的个人工作助手，以可控费用完成日常任务。

首次登录：用户名填 **local**，密码设置为至少 8 位。之后使用同一密码登录。

- **模型连接**：在聊天里输入 `/models`，填写自己的 API 地址、模型和 Key；保存不会调用模型。
- **连续对话**：同一聊天会携带最近的上下文。侧栏可新建、搜索、重命名、删除和切换历史聊天。
- **个人设置**：选择模型连接、回复风格、城市、工作区及本轮工具。
- **费用**：`/budget` 查看准入额度，`/usage` 查看当前聊天的调用记录。
- **关于你**：点击欢迎卡片中的「关于你 · 偏好与洞察」，或输入 `/insights`；管理已确认偏好并查看本地关键词和任务类别图表。
- **资料与产物**：可附加 UTF-8 文本资料；文件写入仍需逐次确认。`/files` 查看工作区。
- **管理上下文**：`/context` 查看携带范围，`/clear` 清空模型上下文但保留聊天记录，`/export` 导出聊天。

默认模型是离线演练。真实模型需启用在线连接；自定义连接目前按用户填写的人民币价格计量，使用量计价与供应商账单可能有差异。
